对当前 git 工作区中已修改的代码进行代码审查。

## 步骤

1. **获取变更范围**
   运行 `git diff` 和 `git diff --staged` 查看所有未提交的代码变更（增、删、改）。同时运行 `git status` 查看新增的未追踪文件。如果没有任何变更，告知用户"没有可审查的代码变更"并停止。

2. **读取审查方案**
   读取 `docs/软件决策与约束/代码审查方案.md`。

3. **逐项审查**
   根据变更涉及的代码层，对照审查方案中对应章节逐项检查：
   - 所有变更：先过全局禁止项（第 2 节，12 项一票否决）
   - UI 层变更：第 3 节
   - ViewModel 变更：第 4 节
   - UseCase 变更：第 5 节
   - Repository 变更：第 6 节
   - 硬件服务变更：第 7 节
   - 持久化层变更：第 8 节
   - 依赖注入变更：第 11 节

   对每条检查项，判断变更代码是否通过。未涉及的层跳过。

4. **输出审查结果**

   按以下格式输出：

   ```
   ## 代码审查结果

   **变更文件：** <列出所有变更文件>

   ### 全局禁止项（第 2 节）
   - [✅/❌] 1. <检查项描述>
   ...

   ### <层名称>（第 N 节）
   - [✅/❌] 1. <检查项描述>：<说明>
   ...

   ### 问题汇总
   <如有未通过项，列出具体文件、行号、问题描述、修复建议>
   <如全部通过，显示"未发现问题">
   ```
