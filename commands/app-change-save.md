# App Change Save — 工作复盘 → 知识沉淀

## 使用场景
完成一段工作（OpenSpec change 归档 / 错误处理 / 一组功能）后，**显式调用**回顾提取值得沉淀的知识，固化到项目文档供后续开发/审查复用。

## 核心原则（不可违背）
1. **每次沉淀必须用户逐条确认**：列候选（内容+位置+价值），用户明确同意后才写入。**绝不默认同意**——每条都要用户点头，不能"全选了事"。
2. **纯显式调用**：不自动触发，不嵌入其他流程自动跑。
3. **跳过已被错误处理覆盖的**：候选若来自刚结束的 `/xxy:app-error`（阶段4/5 已沉淀代码审查/测试），标记并跳过，不重复提议。
4. **去重用语义对比**（非关键词 grep）：判断候选是否已被某条已沉淀知识覆盖（即使措辞不同）。
5. **粒度判据**：只提取满足「会再犯的坑 / 会再用的模式 / 影响后续的决策」之一的；一次性细节、已被现有文档覆盖的不提取。
6. **映射是参考，非机械规则**：分类位置映射给"默认去向"，但每条候选归类时**结合实际情况判断**（陷阱实质 + 章节语义），选最契合的；跨层/有疑问时与用户讨论，**不无脑套映射**。

## 流程

### 1. 确定回顾范围
与用户确认回顾哪段：本次 change / 本次错误处理 / 本次会话 / 指定范围。

### 2. 提取候选（四类）
- 构建/环境配置坑（BuildConfig / applicationIdSuffix / R8 / JDK / 依赖）
- 代码陷阱/API 误用（Compose effect / Flow 时序 / 协程 / 生命周期）
- 架构/流程决策（选 A 不选 B + 理由）
- 临时副产物（调试入口 / 占位，标注临时 + 删除条件）

### 3. 去重（语义对比）
对每个候选，对比已有沉淀（CLAUDE.md / `docs/软件决策与约束/` / 代码审查方案.md）。**语义级**判断是否已覆盖；已覆盖的剔除或合并。

### 4. 跳过错误处理已覆盖
候选若在本次 `/xxy:app-error` 阶段4/5 已沉淀（代码审查项/测试），标记"已被错误处理沉淀"，不重复提议。

### 5. 分类 → 位置（映射为参考，结合实际判断）

默认位置映射：

| 类型 | 默认位置 |
|------|---------|
| 构建/环境配置坑 | CLAUDE.md 构建配置节 |
| 代码陷阱/API 误用 | 代码审查方案.md 对应章节（按下表） |
| 架构/流程决策 | CLAUDE.md 关键架构约束 或 `docs/软件决策与约束/` 新文档 |
| 临时副产物 | CLAUDE.md "Phase X 后增量修改"（标注临时 + 删除条件） |

代码陷阱 → 代码审查方案.md 章节（按涉及层，参考）：

| 陷阱涉及 | 参考章节 |
|---------|---------|
| Compose effect/state/重组/控件 | 第3节（3.1 Compose 规范 / 3.2 自定义控件） |
| ViewModel/MVI | 第4节 |
| BLE/GATT/硬件服务（callbackFlow/资源/时序） | 第7节（7.2 资源清理 / 7.3 并发安全） |
| 高频数据/性能（重组/Flow 降频） | 第10节 |
| 持久化（Room/DataStore） | 第8节 |
| DI（Hilt） | 第11节 |

⚠️ **映射仅为参考默认**：归类时结合陷阱实质与章节语义判断，选最契合的；跨层/有疑问与用户讨论，不无脑套用。

### 6. 提议清单（必须等用户确认）
输出：

| # | 知识摘要 | 类型 | 建议位置 | 已沉淀位置参考（相似已有条目） | 价值（为何值得记） |
|---|---------|------|---------|-------------------------------|------------------|

- "已沉淀位置参考"列：指出已有相似条目（如"已有 7.3 第5项 callbackFlow 时序，本条与之相关但不同"），便于用户判断去重/合并/位置。

**逐条等用户确认**。用户可：全选/部分/调整措辞/调整位置/否决。**未获明确同意的不写。**

### 7. 写入
对确认项，Edit 对应文档（精确插入对应章节，保持现有格式，不动其他）。

### 8. 汇总
输出：沉淀了哪些（位置）+ 跳过了哪些（错误处理覆盖/去重）+ 用户否决的。

## 边界
- `/xxy:app-error` 阶段4/5：bug 专项预防（窄）。本 skill 跳过其已沉淀的。
- `/xxy:app-phase-save`：阶段进度（数字）。不重叠。
- `/xxy:session-memory`：跨会话个人记忆。本 skill 是项目文档（团队共享）。
